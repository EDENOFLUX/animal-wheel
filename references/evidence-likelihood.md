# 证据强度表 · Evidence → Likelihood

> animal-wheel v1.1 的 L2 附件。每条"可观察线索"标出对各动物的**支持方向**与**强度**。
>
> ⚠️ **诚实标注**：Alison & Evy 原框架**未提供概率参数**。本表全部为**启发式估计（heuristic LR）**，用于 log-odds 心智更新的排序与决策，**不是文献实测值**。执行时只取相对强弱（强/中/弱/无反证/反对），不报精确小数当事实。若要严谨参数需自行采集校准数据（目前无来源，故不伪精确）。

## 强度档位（用于 log-odds 更新）

| 档位 | 含义 | log-odds 心智增量（约） | 归一到分布后的示意权重 |
|---|---|---|---|
| 强支持 | 该线索高度典型于某动物 | +2 | ×~7 |
| 中支持 | 常见但不排他 | +1 | ×~3 |
| 弱支持 | 略倾向，弱证据 | +0.5 | ×~1.6 |
| 无反证 | 与判定无关 / 未观察到 | 0 | ×1 |
| 弱反对 | 略降低该动物概率 | −0.5 | ×~0.6 |
| 强反对 | 该行为与该动物典型表现矛盾 | −2 | ×~0.14 |

> 使用法：逐条证据查表 → 对四类动物分别累加 log-odds（初始 0 或 log 先验）→ 取 exp 归一 → 得分布。执行者（LLM）按档位做心智更新即可，无需真跑数值。

## 极性（Good/Bad）判定辅助

极性独立累计，不参与动物分布，规则：
- **强支持某动物的证据若含攻击/强迫/讨好/逃避 → Bad 倾向**；若含尊重/坦诚/倾听 → Good 倾向。
- 单条中性证据不记极性。
- 例：T-Rex "直接坦率"（Good）vs "嘲讽攻击"（Bad）——同动物不同极，靠**语气与是否伤人**区分。
- ND 修正：ASD 直率/少寒暄不记 Bad；对方 ND 时"温度类"证据极性判定权重降为 0。

## 混淆对速查（探针目标）

| 常混淆 | 为何混 | 判别证据 |
|---|---|---|
| Lion ↔ T-Rex | 都强势、都掌控话语权 | T-Rex 带攻击性（嘲讽/伤人）；Lion 不带 |
| Mouse ↔ Bad Mouse | 都少说 | Bad Mouse 有明显回避/敷衍（"都行"逃避）；真 Mouse 会追问学习 |
| Monkey ↔ Bad Monkey | 都热情 | Bad Monkey 有强迫推销感、不容你走 |
| 真 Mouse ↔ ND 耗竭 | 都沉默 | ND 耗竭有感官/执行功能信号，非社交选择 |
